These are the card backgrounds the main page uses. The name is used to match the mood of the message (e.g. angry-fire, happy-sunshine); a name containing transparent marks a transparent sticker. The pink box is where the text goes (values are fractions of the image: 0 = left/top edge, 1 = right/bottom edge; width is usually 0.6–0.9). Font size range is optional, e.g. 80-120. The full-size original is kept for printing; visitors get a lighter WebP copy. If no template is switched on, the main page falls back to the Google Drive folder.
